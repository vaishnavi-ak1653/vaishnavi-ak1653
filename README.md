### How I approach docs

1. **Use it like a new user.** Follow the docs exactly and note every place I get stuck.
2. **Check the source.** Confirm behavior in the code, not just in other docs.
3. **Fix the cause.** Correct the sample, explain why it changed, and keep the wording consistent with the rest of the product.
